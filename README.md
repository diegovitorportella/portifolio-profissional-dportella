# Portfólio Profissional - DIAW

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido como requisito para a disciplina de Desenvolvimento e Integração de Aplicações Web (DIAW) do curso de Engenharia de Software da PUC Minas.

## 🎯 Sobre o Projeto
O objetivo deste sistema é apresentar minha trajetória profissional, projetos, experiências e habilidades como desenvolvedor de software, de maneira moderna e acessível, com suporte aos idiomas Português e Inglês.

## 🚀 Tecnologias Utilizadas
- **Framework Front-end:** Next.js (React) com TypeScript
- **Estilização:** Tailwind CSS e shadcn/ui
- **Envio de E-mails:** EmailJS
- **Hospedagem (Nuvem):** Vercel

## 📂 Estrutura de Diretórios
- `/src/app`: Páginas da aplicação e layout principal.
- `/src/components`: Componentes reutilizáveis (UI, seções, botões).
- `/public`: Arquivos estáticos (imagens, ícones e currículo em PDF).

## 💻 Instruções de Instalação e Execução
1. Clone este repositório: `git clone https://github.com/diegovitorportella/portfolio-profissional-diaw.git`
2. Instale as dependências: `npm install`
3. Execute o servidor de desenvolvimento: `npm run dev`
4. Acesse `http://localhost:3000` no navegador.
